후순위 확장 모듈

지도·통근·실거래·투자성 기능은 기획 확정 후 순차 연결합니다.

클릭해서 열기 ▼

MODULE ROADMAP

예산 판단을 해치지 않는 방식으로 후순위 기능을 붙입니다

본 v20 화면은 세후 자금·대출·매매가 시나리오 판단을 기준 화면으로 유지합니다. 아래 기능들은 현재 계산 로직을 변경하지 않고, 선택 매물 검증용 모듈로만 추가합니다.

지도·단지 검색 모듈

P1

Kakao Local API로 단지명/주소를 검색하고, 아파트·오피스텔 등 결과를 사용자가 직접 선택합니다. 선택 단지와 회사 주소만 지도에 표시합니다.

  • · 검색 결과 자동 확정 금지
  • · 이전 검색 결과 잔상 제거
  • · 회사/단지 마커 라벨 명확화

통근·셔틀 검증 모듈

P2

선택 단지에서 회사까지 ODsay 대중교통 시간을 계산하고, 셔틀 탑승지까지의 도보 접근성을 별도 계산합니다.

  • · 단지별 좌표 기준 개별 계산
  • · 권역 평균 통근시간 적용 금지
  • · 총 소요시간/환승/도보거리 표시

실거래가·평형별 예산 모듈

P3

국토교통부 아파트 매매 실거래가를 활용해 평형별 최근 거래가를 집계하고, Plan A/B 기준으로 진입 가능한 평형을 표시합니다.

  • · 최근 실거래가/거래월/거래건수 표시
  • · 설정 예산 내 가능·초과 구분
  • · 단지명 정규화 후 오매칭 방지

투자성 판단 모듈

P4

가격 모멘텀, 거래 유동성, 예산 진입성, 학군·학원가, 통근·셔틀 조건을 종합해 판단 보조 지표를 제공합니다.

  • · 미래 가격 상승 단정 금지
  • · 데이터 부족 시 부족하다고 표시
  • · 추천 이유와 리스크를 함께 표기

개발 원칙

후순위 모듈은 현재 v20의 자금 계산 로직을 변경하지 않습니다. 모든 외부 API 키는 브라우저에 노출하지 않고 Vercel 환경변수와 서버 API Route를 통해 관리합니다.
